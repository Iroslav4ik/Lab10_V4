1. Скачайте модель "vosk-model-small-ru-0.22" с официального сайта VOSK (https://alphacephei.com/vosk/models).
2. Распакуйте архив в папку "model" в корне проекта.

Инструкция по использованию:
1. Используйте команды: "евро", "доллар", "случайный" - для отображения курса валюты
2. Используйте команду "сохранить" для сохранения результата в файл "rates.txt"
3. Используйте командо "стоп" для остановки программы
